# Compact Unified Revenue visualization

## Goal
Replace the four separate chart panels with one polished, full-width chart panel so the page is easier to scan and uses less vertical space.

## Changes
- Add a compact selector for Revenue trend, Source, Revenue type, and Lifecycle.
- Show one chart at a time in the same stable chart area.
- Add a concise summary and matching legend/context for the selected view.
- Preserve the existing Resolve.io colors, typography, chart data, and surrounding dashboard layout.
- Keep the control keyboard-accessible and responsive.

## Verification
- Check all four chart views on desktop and mobile widths.
- Confirm the page builds without errors and the chart does not resize or overlap nearby content.
